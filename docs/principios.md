1- no inventar features fuera del alcance del PRD.md.

2- Toda nueva feature se debe testar y no debe introducir nuevos bugs ni inconsitencias en otras partes de la aplicación.

3- Una vez desarrollada y testeada una nueva feature se debe commitear para volver fácilmente a esa versión estable, en caso de tener fallas en la siguiente. Preguntarme si deseo hacer el commit.

4- Cada feature desarrollada no debe introducir riesgos de seguridad ni vulnerabilidades al proyecto,exponer claves privadas, ni exponer información de los usuarios 

5- Toda librería, framework, plugins, etc que se utilice en el código debe utilizar su última versión estable
